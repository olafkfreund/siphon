# Plan: ops basics (backup and restore, metrics, retention)

## Approved decisions (from the spec; self-contained)

**State.** Everything lives next to `server.db`, in `dir := filepath.Dir(db)`:
- the db file (plus `-wal` and `-shm`);
- `dir/secrets/`, the pasted secrets (`secretsDir`, `internal/web/forms.go:170`);
- `dir/credentials/`, the subscription logins (`internal/cred/cred.go:28`), in subdirectories such as `chatgpt/auth.json`.

**Never archived:** `siphon.yaml`, `server.token`, `actions_dir`, the `.lock` file, and anything else in `dir`.

**`siphon backup create [-config f | -db path] [--force] <file|->`**
- A local command. `-db` wins. Otherwise `-config` (default `siphon.yaml`) is loaded with `config.Load` for `Server.DB`.
- **Snapshot:**
  - Open the db raw with `sql.Open("sqlite", "file:"+db+"?mode=ro&_pragma=busy_timeout(5000)")`. This does **not** use `store.Open`, which would run migrations on a live db that an older daemon owns.
  - Take no lock.
  - Run `VACUUM INTO '<tmp>/state.db'`. `tmp` is `os.MkdirTemp(dir, ".backup-*")`, mode 0700, removed with `defer os.RemoveAll`.
- **Archive:** a tar.gz with these entries, in order:
  1. `siphon-backup.json`: `{"format":1,"version":<siphon version>,"schema":<max(version) FROM schema_migrations of the snapshot>,"created":<RFC 3339 UTC>}`.
  2. `state.db`: always this name.
  3. `secrets/…`, then `credentials/…`: directories and regular files only. Anything else (a symlink, socket or device) is skipped with a stderr warning naming the path. A missing directory is fine.
- **Ordering:** the db is snapshotted first, then the directories are read.
- **File target:**
  - Refuse an existing `<file>` unless `--force`.
  - Write `<file>.tmp-<rand>`, created `O_CREATE|O_EXCL|O_WRONLY` with mode 0600. Then fsync, close, and rename it to `<file>`.
  - On any error, remove the tmp file.
- **`-` target:** writes to stdout, and is refused when stdout is a terminal (`term.IsTerminal`).
- **Output:** one stderr line, `backed up to <file> (<size>, N secrets, M logins)`. Never print file contents or secret names.

**`siphon backup restore [-config f | -db path] [--yes] <file|->`**
1. **Owner check:** `os.Getuid()` must equal the owner uid of `dir`. Otherwise exit 1: "run as the user that owns <dir> (sudo -u <owner> …)".
2. **Lock:** `store.Lock(db)` (`internal/store/store.go:374`). On failure, exit **5**: "siphon is running (it holds <db>.lock): stop it first".
3. **Extract** to a 0700 temp dir `os.MkdirTemp(dir, ".restore-*")`, removed on exit unless it was swapped in. Any of the following rejects the whole archive, with nothing touched:
   - **Names:** an absolute name, a `..` element, a symlink, hardlink or any type other than a dir or regular file, a name outside `siphon-backup.json`, `state.db`, `secrets/**` and `credentials/**`, or a duplicate name.
   - **Size:** a total over 1 GiB (counted while copying, with `io.LimitReader`).
   - **Manifest:** missing, or `format != 1`, or `schema > store.NewestMigration()` ("backup is from a newer siphon (<version>)"). The migration file names `NNNN_*.sql` compare as strings.
   - **Database:** `state.db` is missing, or `PRAGMA integrity_check` is not `ok`.
4. **Confirm:** if the current `<db>` exists, print what is replaced (the db size, the `count(*) FROM jobs`, and the counts of files in `secrets/` and `credentials/`).
   - On a TTY (stdin), ask y/N.
   - Without a TTY and without `--yes`, exit **2** ("restore replaces existing state: pass --yes").
   - Reading the archive from `-` uses stdin, so the TTY prompt can't be answered from it. With `-`, `--yes` is required when state exists.
5. **Swap**, all as renames within `dir`:
   1. `mkdir dir/pre-restore-<UTC 20060102T150405Z>` (0700).
   2. Move `<db>`, `<db>-wal`, `<db>-shm`, `secrets/` and `credentials/` into it (each only if it exists).
   3. Move the extracted `state.db` to `<db>`, and `secrets/` and `credentials/` into `dir`.
6. **Modes:** files 0600 and directories 0700, set while extracting.
7. **Finish:** print `restored; the previous state is in <dir>/pre-restore-…; start siphon, then run siphon validate`.

**Exit codes for local commands.** Add `type exitError struct{ code int; err error }` to `cmd/siphon`, with `Error`/`Unwrap`. `main` maps it with `errors.As` to `os.Exit(code)`; everything else stays exit 1. Codes: 2 usage / needs `--yes`, 5 running.

**`GET /metrics`**
- Registered with `s.api(...)` (`internal/web/api.go:129`), which gives bearer token auth plus the failed-auth rate limit.
- `Content-Type: text/plain; version=0.0.4; charset=utf-8`, hand-written. `# HELP` and `# TYPE <name> gauge` for each family, series sorted by label value.
- All values are gauges from one read transaction in `store.Metrics(db, now)`:

| Metric | Labels | Value |
|---|---|---|
| `siphon_build_info` | `version` | 1 |
| `siphon_jobs` | `state` | `count(*) GROUP BY state`, all states present, including 0 for the known states |
| `siphon_jobs_finished_last_hour` | `state` ∈ done, failed, cancelled | `finished_at >= now-1h` |
| `siphon_queue_oldest_seconds` | — | now − min(created_at) of queued jobs, 0 if none |
| `siphon_approvals_pending` | — | jobs in pending_approval |
| `siphon_approval_oldest_seconds` | — | now − min(created_at) of pending_approval jobs, 0 if none |
| `siphon_agent_runs_today` | — | `CountAgentJobsSince(tx, start of the UTC day)`, the same window as the cap (check `internal/job` for the cap's window and use the same one) |
| `siphon_agent_runs_daily_limit` | — | `cfg.Limits.AgentRunsPerDay` |
| `siphon_source_failing` | `source` | 1 if `source_state.failing_since IS NOT NULL`, else 0 |
| `siphon_source_last_poll_timestamp_seconds` | `source` | `last_poll_at`/1000 (omitted when NULL) |
| `siphon_rule_error` | `rule` | 1 if a `rule_error` row exists, else 0 |
| `siphon_notifications` | `channel`, `state` | `notifications GROUP BY channel, state` |

- **Labels:** source, rule and channel series are emitted only for names in the **running config** (`s.Config()`). Polled sources only for the source metrics; every rule; every notify channel. Rows for deleted names are dropped.
- **Escaping:** label values are escaped per the text format (`\\`, `\"`, `\n`), although names are already restricted.
- **Never in a metric:** a job id, an error text, a URL or any event data.

**Retention** (`server.retention`, operator-only; `server` is not an overlay kind, `internal/config/overlay.go:42`):
- `Jobs`, `Audit`, `SeenEvents` are `Duration` fields with yaml keys `jobs`, `audit`, `seen_events`. Go durations, no `d` unit.
- **0 or unset** means the default (720h, 720h, 168h).
- **Minimum:** a non-zero value under 24h is a validation error: `server.retention.<key>: must be at least 24h`.
- **Store:** `store.Cleanup(db, now)` becomes `store.Cleanup(db, now, store.Retention{Jobs, Audit, Seen time.Duration})`. A zero field uses the default constant (`internal/store/store.go:283`). The audit delete uses `Audit`, and the job and notification deletes use `Jobs`, as now. Seen events use `Seen`.
- **Caller:** `internal/job/queue.go:159` passes `p.Config().Server.Retention`, read on every run, so a reload applies at the next daily run.

**NixOS** `services.siphon.backup = { enable = false; dir = "/var/backup/siphon"; calendar = "daily"; keep = 7; }`:
- **Directory:** `systemd.tmpfiles` creates `dir` with mode 0700, owned `siphon:siphon`.
- **`siphon-backup.service`:**
  - oneshot, `User`/`Group = siphon`, `UMask = 0077`, `ReadWritePaths = [ dir stateDir ]` (`VACUUM INTO` writes its temp copy into `stateDir`);
  - the main unit's hardening where it applies;
  - script:
    1. `siphon backup create -db ${stateDir}/state.db ${dir}/siphon-$(date -u +%Y%m%dT%H%M%SZ).tar.gz`;
    2. then delete all but the newest `keep` `siphon-*.tar.gz` (`ls -1t … | tail -n +$((keep+1)) | xargs -r rm --`).
- **`siphon-backup.timer`:** `OnCalendar = calendar`, `Persistent = true`, `RandomizedDelaySec = "10min"`.
- **Restore** is manual and documented. There is no unit for it.

**Docs:** `docs/tasks/backup-and-monitoring.md`, covering:
- backup and restore, and moving to a new host;
- the archive's contents and how sensitive they are, with age/restic pipes shown first;
- the NixOS timer;
- OCI: `podman exec <c> siphon backup create -db /data/state.db - > x.tar.gz`;
- metrics, with a Prometheus scrape config (`authorization: { credentials_file: … }`) and four alerts:
  - `siphon_jobs_finished_last_hour{state="failed"} > 0`;
  - `siphon_approval_oldest_seconds > 72000`;
  - `siphon_source_failing == 1`;
  - `siphon_notifications{state="pending"} > 0` for 30m;
- retention.

## Rollback

- **Code:** revert the merge commit. There is no migration.
- **Config:** `server.retention` in a `siphon.yaml` is then rejected as an unknown key (decoding is strict, `KnownFields(true)`, `internal/config/config.go:531`), so remove it before downgrading.
- **NixOS:** set `backup.enable = false`. Archives already written stay in `dir`.
- **After a restore:** the previous state is in `dir/pre-restore-*/` and can be moved back the same way.

## Deviations

- Step 2: `siphon_agent_runs_today` uses a rolling 24h window (`now-24h`), not the start of the UTC day, because that is what the daily cap uses (`internal/job/pipeline.go:298`). `store.GetMetrics` also fills `Metrics.Approvals` from the `pending_approval` job count.
- Step 3: `internal/store/snapshot.go` also holds `Integrity(path)` and `JobCount(path)` (read-only opens), beside `Snapshot`, so `cmd/siphon` has no SQL. Restore creates `pre-restore-*` only when there is state to move aside, and creates `dir` (0700) if it does not exist.
- Step 4: the version reaches `/metrics` through a new `web.Options.Version` field, set from `version` in `cmd/siphon/main.go` (the web package had no version). The route is registered in `apiRoutes` (`api.go`), not `diagapi.go`/`web.go`. Source series cover polled sources only (`Source.Polled()`, as in the pollers and `data.go`).
