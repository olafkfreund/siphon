# Intent: bring the docs up to date with main

## Problem

A review of every doc page against the code on main (675db3a) found that the
hand-written docs fell behind the last two weeks of features:

- 14 claims now contradict the code, for example:
  - portal sessions "end on restart" (wrong since #119);
  - "Siphon has no clock source" (schedule sources exist);
  - `on: each` "dedupes for 7 days";
  - "three agent kinds" (there are four);
  - the polkit rule and the units it names;
  - cooldown "only for agents".
- These features have no docs:
  - the routine editor, its recipes and the Reference panel;
  - the YAML editor's live validation;
  - `servicenow:` in the overview pages;
  - notification source recovery;
  - two MCP tools;
  - `go generate ./docs`;
  - the newer packages in the AGENTS.md layout;
  - pages and templates missing from the indexes.
- Counts and lists are stale: there are 52 templates, not "~30"; 10 webhook
  auth modes are listed as 4; 30 catalog services are described as "GitHub,
  GitLab, AWS".
- `siphon explain` text and the `connect` usage line have small errors.

The generated docs (`cli.md`, `connections/README.md`, `llms-full.txt`),
the links and the anchors are all current.

## Proposed outcome

Every finding in the review is fixed. Docs, `llms.txt`, AGENTS.md, the
`explain` text and the CLI usage agree with the code. The generated files are
regenerated, and `go test ./docs/...` passes.

## Affected users and systems

- Readers of README.md, docs/ and llms.txt.
- Agents that operate Siphon through `docs/llm.md` and `siphon guide`.
- Contributors who use AGENTS.md.

## Constraints

- Change docs and help text only. The one code bug found (routine steps of
  kind `servicenow` show an empty kind on the job page) goes to the bug-fix
  issue instead.
- Rerun `go generate ./docs` after the change to the usage line.

None.
