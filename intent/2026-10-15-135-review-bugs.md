# Intent: fix the verified bugs from the codex/agy review

## Problem

codex and agy reviewed main independently. A fresh Opus agent checked all 19
findings against the code; 11 are real, 5 of them reproduced with scratch
tests:

- **HIGH:** the daemon panics (nil pointer) when an agent's MCP source is
  removed while one of its jobs is queued or waiting for approval. Every
  queued job is then at risk.
- **MEDIUM:**
  - rule errors reach the daemon log without masking, so event values or
    secrets can leak into the journal;
  - each HTTP poll leaves an idle connection open forever (50 polls left 50
    sockets and 150 goroutines);
  - deleting a login removes the wrong secret file name, so the plaintext
    API key stays on disk;
  - the portal's Review → Confirm drops pasted secrets: a new one fails with
    422, and a rotated one silently keeps the old key.
- **LOW:**
  - when stopping a timed-out unit fails, the error is ignored;
  - `NeedsApproval` returns false (no approval) for a missing agent, which
    only reaches the rule tester's label;
  - an `is_error` result with exit code 0 counts as done;
  - `siphon credentials ls` and `credentials import` ignore portal-added
    credentials;
  - the editor's Review check skips the model-endpoint check that the save
    applies;
  - a replayed webhook overwrites the source's "last event";
  - ServiceNow routine steps show a blank kind on the routine and job pages.

## Proposed outcome

Each defect is fixed at its root, with a regression test that fails on main.
No change of design.

## Affected users and systems

The daemon (job pipeline, polling), the portal editors, the CLI's local
`credentials` commands, and anyone with a login or a removed MCP source.

## Constraints

- **Out of scope** (the review rejected or deferred these):
  - restoring a revision of a deleted notify channel;
  - the operator role for Notion acceptance (by design; only document it);
  - the order of secret publish and commit (deliberate);
  - `stripQuoted` missing unquoted values in stored errors (a separate
    decision).
- Masking in logs reuses the existing helper (`pollErrText`), not a new one.

## Open questions

None.
