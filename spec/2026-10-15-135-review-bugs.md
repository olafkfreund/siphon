# Spec: fix the verified bugs from the codex/agy review

## Design

The IDs are the verifier's: C = codex, A = agy.

1. **A1, the removed MCP source.** In `agentExec` (`internal/job/pipeline.go`
   at about line 462), if `cfg.Sources[name] == nil`, fail the job with
   "mcp source <name> no longer exists". The agent is snapshotted, but
   sources are read live by design. Routine agent steps share `agentExec`,
   so they are covered too.
2. **C1, logging rule errors.** The three `slog.Warn` calls that log
   `ruleErr` (`hooks.go`, `schedule.go`, `pipeline.go` for agent results)
   log `pollErrText(cfg, ruleErr)`: masked, quoted values blanked, and
   capped. The webhook path takes `cfg := p.Config()` once and uses it for
   both the call and the log.
3. **C4, the poll connection leak.**
   - `guardedClient` (`internal/source/netguard.go`) sets
     `IdleConnTimeout: 90 * time.Second` on its transport.
   - `limitedTransport` forwards `CloseIdleConnections` to its base.
   - `HTTP.Poll` runs `defer client.CloseIdleConnections()`.

   The timeout covers every guarded client (HTTP, MCP, ServiceNow); the
   defer frees the one-shot poll at once.
4. **A3, the login secret file name.** `removeLogin`
   (`internal/web/configweb.go:610`) removes
   `config.SecretFileName("credentials", name, "api_key")`, and still
   removes the legacy name too.
5. **A2, Review → Confirm with secrets.** When `pending` secrets exist,
   `cfgPost`'s review shows the diff without the Confirm form, plus a note:
   "Secrets are not kept by Review: enter them again and use Save &
   apply."
6. **C2, a unit outliving its job.** `runUnit` (`internal/action/template.go`)
   returns `fmt.Errorf("unit %s may still be running: %w", unit, err)`
   when `stopUnits` fails after a cancel or timeout, so the job output says
   so.
7. **A6.** `Config.NeedsApproval` mirrors `StepNeedsApproval`: a missing
   agent or a nil `Approve` means approval is needed. Fix the drifted doc
   comment too.
8. **A7.** The agent result check (`internal/action/agent.go:123`) also
   treats `is_error: true` as a failure.
9. **A9.** `siphon credentials ls` and `credentials import`
   (`cmd/siphon/main.go:569`) apply `dbOverlay` like every other local
   command, through `tryLoad(path, items)`.
10. **A11.** Delete `checkEdit` (`configweb.go:396`). Its callers use
    `s.dryRun`, which includes `credsCheck` and `editMu`. The cost is a DNS
    lookup for credential edits during live validation, which is
    acceptable.
11. **A13.** The webhook path calls `SetSourceEvent` only for a delivery
    that isn't a duplicate (after `handleEvent`, `if !dup`).
12. **A15.** Add a `servicenow` case to the step switches in `editors.go`
    (`editExtras`) and `pages.go` (`jobDetail`). It reuses `snTable`.
13. **Docs.** The role table in docs/tasks/sso.md notes that operators
    accept Notion verification tokens.

## Alternatives rejected

- **A1:** skipping the missing source and running the agent without it.
  Silently changing an agent's tools is worse than a clear failure.
- **C4:** `DisableKeepAlives`. It would cost a TLS handshake per request on
  long-lived MCP clients.
- **A2:** keeping secrets across Review in a server-side store. That adds
  state for a rare flow; asking the user to re-enter is honest and small.
- **A11:** adding `credsCheck` into `checkEdit`. That keeps two copies,
  which is the very drift that caused this bug.

## Risks

- **C1:** the log lines get shorter (capped at 300 bytes). That's
  acceptable.
- **A11:** live validation now does DNS for credential URLs. It's
  debounced at 400 ms, admin only.
- **Conflicts with #132,** which also edits `editors.go`, `pages.go` and
  `api.go`. Rebase after whichever merges first.

## Verification

- A regression test for each item that fails on main:
  - the removed-MCP-source job fails rather than panicking;
  - a captured slog has no secret;
  - 50 polls leave at most 1 server connection;
  - the secret file is gone after `removeLogin`;
  - Review with a pending secret has no Confirm form;
  - a stop failure returns an error;
  - `NeedsApproval` is true for a missing agent;
  - `is_error` with exit 0 fails;
  - `credentials ls` lists an overlay credential;
  - `/check` gives 422 on a private model endpoint;
  - a replay keeps the last event;
  - the ServiceNow step kind renders.
- `go vet ./... && go test -race ./...`.
- An Opus review of the diff against the plan.
