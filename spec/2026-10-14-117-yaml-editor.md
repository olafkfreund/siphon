# Spec: editing YAML in the portal feels like a code editor, with live validation

## Design

### 1. The validate endpoint, `internal/web/configweb.go`

- **The route:** add `"validate"` to the verbs at `:74`:
  `POST /config/{kind}/{name}/validate`. It goes through the same `h(...)`
  wrapper, so the same admin gate and CSRF check apply.
- **The shared logic:** in `cfgPost`, `"validate"` takes the `"check"`
  path through `itemYAMLFromRequest`, the stale-rev check and `s.prepare`
  (`:254-300`). It's refactored into a helper that returns the diff and
  an error message, so `check` and `validate` share it.
- **What it renders:** never the page. It renders the fragment template
  `cfgvalid` with status 200, so htmx swaps it.
  - **On success:** `<p class="yaml-status ok" data-line="">Valid · N changes</p>`,
    where N is the count of `+` and `-` lines in the diff. "Valid · no
    change" when the diff is empty.
  - **On failure:** `<p class="yaml-status err" data-line="L">MSG</p>`,
    where `L` is the first `line (\d+)` in the message, if any.
- **It never writes:** `prepare` only computes. No commit is made, and no
  pending secrets are written.

### 2. The markup, `templates/config.html` (`:38-44`)

- The textarea gains `class="mono code-input"`, plus `hx-post="{{.Base}}/validate"`,
  `hx-trigger="input changed delay:600ms"`, `hx-target="#yaml-status"`,
  `hx-swap="outerHTML"` and `hx-include="closest form"`.
- **Admin only:** the `hx-*` attributes are rendered only when `can $.Role "admin"`,
  like the buttons.
- **The status line:** `<p id="yaml-status" class="yaml-status" aria-live="polite"></p>`,
  after the textarea. The fragment carries the same id.

### 3. The editor behaviour, `static/app.js`

`initCodeEditors()`, about 70 lines, is bound on `DOMContentLoaded` and
`htmx:afterSwap`, once per textarea:

- **The wrapper:** it wraps each `textarea.code-input` in
  `div.code-editor` with `div.code-gutter[aria-hidden=true]`. It fills the
  gutter with line numbers on `input` and on resize, and syncs its
  `scrollTop` on `scroll`.
- **Keys:**
  - **Tab** inserts 2 spaces at the caret, or indents every line of the
    selection.
  - **Shift+Tab** removes up to 2 leading spaces per line.
  - **Enter** keeps the current line's indent, plus 2 if the line ends in
    `:`, or is `- key:`.
  - **Escape, then Tab,** leaves the box, so the keyboard isn't trapped
    (an accessibility requirement).
  - It uses `setRangeText`, so the browser's undo stays mostly intact.
- **The error line:** after an `htmx:afterSwap` of `#yaml-status`, it
  reads `data-line`, marks that gutter line `.is-err`, and clears it on
  `ok`.

### 4. The styles, `static/style.css`

- **`.code-editor`:** a grid with the gutter, then the textarea, one
  shared font and line-height.
- **`.code-gutter`:** right-aligned, `--muted`, `user-select: none`, and
  an overflow-hidden scroll mirror.
- **`.code-gutter .is-err`:** a `--coral` background tint.
- **`.code-input`:** `tab-size: 2`, `white-space: pre`, `overflow: auto`.
- **`.yaml-status.ok` / `.err`:** `--kelp` and `--coral` text, plus an
  icon from the sprite. No emoji.

## Alternatives rejected

- **Vendored editors** (CodeMirror 6, Monaco, CodeJar): rejected at the
  intent, for CSP, size and reliability.
- **Syntax colouring:** deferred (intent question 1).
- **Validating in JS:** the server already knows the schema and the
  overlay rules. Duplicating them in JS would drift.

## Risks

- **The gutter drifting out of line with the text** under soft-wrap:
  `white-space: pre` disables wrapping, so the box scrolls sideways
  instead.
- **Typing cost:** one validate per 600 ms pause, admin only, and no
  writes.
- **Undo:** `setRangeText` keeps native undo in Chromium and Firefox. Older
  browsers lose it for the keys it handles, which is acceptable.

## Verification

- **`internal/web`:**
  - **Valid YAML:** `/config/rules/r1/validate` returns 200 with "Valid",
    without changing the revision.
  - **Invalid YAML:** it returns `err` with `data-line`.
  - **A viewer** is refused.
  - **CSRF** is required.
  - A secret in the form isn't written.
  - `TestTemplatesAreCSPClean` passes.
- **`go vet ./... && go test -race ./...`.**
- **Visual and keyboard, on siphon-dev:**
  - Tab, Shift+Tab, Enter;
  - the line numbers;

  - Escape then Tab leaves the box;
